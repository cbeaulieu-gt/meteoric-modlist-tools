# Implementation plans

These are the step-by-step implementation plans followed while building the tools in
this repository — task checklists, exact commands, and verification steps for each
feature.

They are **not** user documentation and are not maintained as such. They capture the
state of the plan at the time each feature was built, some reference tools and paths
that live in a different (private) repository, and some checkboxes describe steps
that were only ever meant to run once. For how to actually use the tools, see the
[README](../../README.md).

`plans/` holds the task-by-task checklists — how a feature got built. `design/` holds
the specs — what was being built and why. Every plan here has a matching spec, but not
every spec has a plan.
